# 評量報讀系統

以照片、PDF 或貼上文字建立繁體中文報讀題卡，支援框選辨識、語速、字級與語音調整。

公開網站：https://liniris1023.github.io/sped-exam-reader/

## 使用方式

1. 拍照或選擇照片、PDF；也可以直接貼上文字。
2. 圖片載入後可直接畫框，不必先等待整頁辨識。需要整頁文字時，按「整頁拆題」。
3. 核對辨識文字與數學符號，再按「立即報讀文字」。框選後不自動播放，讓平板保留明確的使用者播放手勢。
4. 下載 JSON 題目檔備份，或從 QR 視窗選擇連同文字題目分享。QR 容量不足時可複製完整網址或傳送題目檔。

預設在瀏覽器本機辨識；首次需連網下載 OCR 套件與繁體中文字庫。選擇 OCR.space 雲端模式或填入 Gemini 金鑰，會把辨識圖片送至對應服務。雲端辨識可能受額度與服務狀態限制。裝置語音是否使用網路依作業系統語音服務而定。

文字卡保存在此瀏覽器，原稿圖片只存在當次頁面的記憶體中。分享連結與題目檔只包含文字，不含原稿或金鑰；分享連結包含可還原的題目，請只分享給需要的人。Gemini 金鑰僅保留於當次分頁記憶體，重新整理後需重填。共用平板使用後請清空紀錄。

OCR 可能誤讀、漏字或改變閱讀順序。分數、注音、圖表、手寫、複雜直排、多欄試卷應對照原稿逐項核對。畫布上的「文字卡預覽」是重繪文字，不是原始試卷，長文可能未完整顯示。可用右側文字卡或貼上文字完成鍵盤報讀。

## 維護與驗證

使用 Node.js 18 以上：

```sh
npm ci
npm run build
npx playwright install chromium
npm test
```

`assets/tailwind.css` 已提交，可直接透過 GitHub Pages 提供靜態網站。修改 HTML 樣式後請重新執行建置。`qa/regression.cjs` 會啟動暫時的本機 HTTP 伺服器，檢查分享、匯入、PDF、本機儲存失敗、OCR 錯誤回收、窄螢幕與無障礙規則，並將測試結果及截圖輸出至 `qa/results/`。PDF 模組與部分前端套件仍需網路可用。

檢查發現與處理範圍詳見 [REVIEW.md](REVIEW.md)。
