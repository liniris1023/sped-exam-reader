第一次使用：怎麼取得 GitHub 權杖？（約 2 分鐘，只要做一次）
  1. 登入 GitHub 後打開 建立權杖頁面（Fine-grained token）。
  2. Token name 填「評量報讀上傳」；Expiration 選 1 年（或自訂）。
  3. Repository access 選「Only select repositories」，再選 sped-exam-reader。
  4. Permissions → Repository permissions → Contents 改成「Read and write」。其他都不用動。
  5. 按最下面的 Generate token，複製 github_pat_ 開頭的那串字，貼到上面再按「連線」。

這個權杖只能修改這一個存放庫的檔案。權杖不會上傳到任何地方，只存在這台電腦的瀏覽器裡。
