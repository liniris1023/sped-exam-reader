    這台平板的考卷

      📱 學生用平板掃這個 QR Code

      掃描後會打開評量報讀小幫手。要讓學生掃了直接看到某一份考卷，請按那份考卷旁邊的「📱 QR」。

      使用說明
      1. 國語考卷是直的，請先按上面的 直式（國語）；數學、社會選 橫式。
      2. 打開考卷後，每一題會出現有編號的框框，點一下框框就會唸那一題；按下面的 下一題 ⏭ 可以一題一題聽。
      3. 沒有框到的地方，按 ✋ 框選朗讀，用手指把文字框起來就會唸。
      4. 拍照時考卷要放平、光線要亮，字會辨識得比較準。
      5. 老師放考卷到網站上：在 GitHub 存放庫建立 tests 資料夾，把 PDF 上傳進去（可以再分成 tests/國語、tests/數學 子資料夾）。幾分鐘後，「老師放在網站上的考卷」就會出現，全班平板都看得到。每份考卷旁的 QR 可以產生直接開這份考卷的 QR Code。
      6. 「這台平板的考卷」只存在這台平板的瀏覽器裡，其他平板看不到；清除瀏覽器資料後會不見。
      100%

      直接點考卷上的題目，就會唸那一題；也可以按下面的「下一題」。

      ✋ 用手指拖曳，把要聽的文字框起來。再按一次「框選朗讀」可以關掉。

      🔊 按喇叭聽題目

      題目分錯了嗎？換一種方式重新辨識：

        ✏️ 老師編輯：語音報讀內容

        可以修改每一段要唸的文字、分開或合併題目、改大題的題型、關閉單一小題的語音。題目畫面不會被修改，錯別字也會照原樣保留。寫注音的小題固定不報讀。

          文字辨識方式

          模型

          取得 API Key：到 Google AI Studio 登入，按「Create API key」後複製貼上。Key 只存在這台裝置的瀏覽器裡。

          報讀方式

          固定規則：「寫注音」大題只唸大題名稱，小題完全不唸；「改錯字、圈出錯字、找出錯別字」每次只唸一小題，由學生自己按下一題。

          不報讀的題目會用紅色虛線框起來，學生點了會聽到「這一題不報讀，請自己看題目」。

          學生用連結與 QR Code

          學生掃 QR Code 開啟後，會自動套用目前的排列方式與上面的設定。

          預先載入的 PDF（選填）

          拿到這個連結或 QR Code 的人都能使用你的 Key，請只給自己的學生，不要貼到公開網頁。

          老師編輯模式

          打開後，考卷下方會出現「語音報讀內容」編輯區，可以預聽、修改、分段、改題型。網站上的考卷可以直接儲存並同步給學生。
